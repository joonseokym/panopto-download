# Panopto Downloader {{VERSION}} 설치

사용하는 브라우저와 다운로드 방식을 골라 ZIP **하나**를 받으세요. 두 방식 모두 현재 영상 다운로드, 폴더 전체 다운로드와 0.25~4배 배속을 제공합니다. 하위 폴더는 포함하지 않습니다.

| 브라우저 | 확장 프로그램 전용 | 로컬 도우미 포함 |
| --- | --- | --- |
| Chrome | `panopto-{{VERSION}}-chrome-standalone.zip` | `panopto-{{VERSION}}-chrome-with-helper.zip` |
| Safari | `panopto-{{VERSION}}-safari-standalone-source.zip` | `panopto-{{VERSION}}-safari-with-helper-source.zip` |

**확장 프로그램 전용:** 별도 프로그램 실행 없이 브라우저에서 다운로드합니다. 기본 저장 위치는 브라우저의 다운로드 폴더(보통 Downloads)입니다. 다운로드 중 강의 탭과 다운로드 관리 탭을 열어 두세요.

**로컬 도우미 포함:** 도우미 소스·실행기를 함께 제공합니다. Python 3.9 이상과 FFmpeg·FFprobe는 별도로 설치해야 합니다. HLS를 MP4로 변환·검증하고, 저장할 폴더 경로를 직접 지정할 수 있습니다. 기본값은 `~/Downloads`입니다.

## Chrome

1. ZIP을 풀어 계속 사용할 폴더에 둡니다. 설치 후에도 폴더를 지우지 마세요.
2. `chrome://extensions`에서 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 눌러 압축을 푼 폴더의 `extension/`을 선택합니다.
4. 도우미 포함판을 골랐다면 아래 도우미 연결을 진행합니다. 확장 전용판은 연결 설정이 없습니다.
5. 로그인한 Panopto 페이지를 새로고침합니다.

Chrome Web Store 설치가 아닌 개발자 모드로 소스를 로드하는 방식입니다.

## Safari

Safari ZIP은 **빌드용 소스**입니다. 일반 사용자에게 바로 설치 가능한 Developer ID 서명·공증 앱은 이 릴리스에 포함되지 않습니다.

### 임시 설치

지원되는 Safari에서는 **Safari 설정 → 개발자 → Add Temporary Extension…**에서 압축을 푼 폴더의 `extension/`을 선택합니다. 개발자 설정이 보이지 않으면 고급 설정에서 웹 개발자 기능 표시를 켭니다. 임시 설치 지원 여부와 유지 기간은 Safari 버전에 따릅니다.

### 로컬 앱 빌드

Xcode 전체 설치와 Node.js 20 이상이 필요합니다. 압축을 푼 폴더에서 `Build Safari.command`를 실행하면 선택한 방식의 서명하지 않은 개발 앱을 만듭니다. 본인의 Apple Development Team ID가 있다면 터미널에서 다음처럼 전달합니다.

```sh
./Build\ Safari.command YOUR_TEAM_ID
```

생성 위치:

- 확장 프로그램 전용: `dist/safari/Panopto Downloader.app`
- 도우미 포함: `dist/with-helper/safari/Panopto Downloader Helper.app`

로컬 개발 서명한 앱을 Applications 폴더에 넣고 실행한 뒤 Safari 설정의 **확장 프로그램**에서 활성화하고 사용하는 Panopto 사이트의 접근을 허용합니다. 서명하지 않은 빌드는 개발용이며 일반 배포용 앱이 아닙니다. 도우미 포함판은 앱 설치와 별도로 아래 도우미 연결도 필요합니다.

## 도우미 포함판 연결

1. Python 3.9 이상과 FFmpeg·FFprobe를 설치합니다. macOS에서 Homebrew를 사용한다면 FFmpeg 설치 명령은 `brew install ffmpeg`입니다.
2. macOS에서는 ZIP 안의 `helper/start.command`를 더블클릭합니다. 다른 환경에서는 `helper/` 폴더에서 `python3 panopto_download.py`를 실행합니다.
3. `http://127.0.0.1:8765`를 열고 **확장 프로그램 연결 코드**를 복사합니다.
4. 확장 프로그램 설정에서 코드를 붙여 넣고 **저장 · 연결**을 누릅니다. 필요하면 저장 폴더 경로를 바꿉니다.
5. 로그인한 Panopto 페이지를 새로고침합니다. 다운로드 중 도우미 터미널과 강의 탭을 열어 두세요. 도우미 종료는 `Ctrl+C`입니다.

도우미는 이 컴퓨터의 `127.0.0.1:8765`에만 연결합니다. 연결 코드를 다른 사람에게 공유하지 마세요. 더 자세한 사용법은 도우미 포함 ZIP의 `helper/README.md`에 있습니다.

## 사용·전환·업데이트

영상 페이지의 **이 영상 다운로드**, 폴더 목록의 **폴더 전체 다운로드**, 확장 팝업에서 작업을 시작합니다. 배속 선택은 재생에만 적용되며 저장 파일은 원래 속도를 유지합니다.

한 브라우저에 두 방식을 동시에 활성화하지 마세요. 전환하려면 진행 중인 작업을 마친 뒤 기존 확장을 끄고 새 확장을 설치·활성화하고 Panopto 페이지를 새로고침합니다. 도우미 포함판에서 확장 전용판으로 바꾸면 도우미를 종료해도 됩니다. 두 방식의 설정·작업 내역은 자동 이전되지 않으며, 도우미가 꺼졌을 때 확장 전용 방식으로 자동 전환하지 않습니다.

Chrome 업데이트는 기존 설치 폴더를 새 릴리스 파일로 교체한 뒤 `chrome://extensions`의 새로고침을 누릅니다. Safari 로컬 앱은 새 소스로 다시 빌드·교체하고, 임시 설치는 새 소스를 다시 로드합니다. 두 경우 모두 열려 있던 Panopto 페이지를 새로고침합니다.

## 확장 프로그램 전용판의 제약

- 관리 탭·브라우저를 닫거나 네트워크가 끊기면 진행 중 작업이 중단될 수 있으며, 완전한 재개는 보장하지 않습니다.
- 대용량 작업은 브라우저의 임시 디스크 공간을 사용합니다. 임시 디스크 저장을 지원하지 않으면 파일당 256 MiB 메모리 제한이 적용됩니다. 최종 저장을 확인한 뒤 **임시 파일 정리**를 사용하세요.
- TS 영상은 `.ts`로 저장하며 MP4로 변환하지 않습니다. 암호화된 HLS, 진행 중 방송, 별도 음성 결합 등 복잡한 구성은 지원하지 않습니다.
- Safari는 저장 요청을 브라우저에 전달한 뒤 실제 저장 완료·취소를 Safari 다운로드 목록에서 확인합니다. 저장 위치는 **Safari 설정 → 일반 → 파일 다운로드 위치**를 따릅니다.
- 지원되는 Chrome에서는 확장 설정의 폴더 선택, 다운로드 폴더 내 하위 경로 또는 저장 대화상자를 사용할 수 있습니다. 임의의 절대 경로에 권한 없이 저장하지는 않습니다.
