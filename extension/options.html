저장 위치 설정

Panopto 다운로드 확장 · 브라우저에서 바로 저장

다운로드가 진행되는 동안 Panopto 강의 탭과 다운로드 작업 탭을 모두 열어 두세요. 브라우저를 종료하거나 작업 탭을 닫으면 진행 중인 영상이 중단될 수 있습니다.

기본 저장 위치는 브라우저에 설정된 다운로드 폴더입니다. 일반적으로 Downloads 폴더이며, 브라우저에서 위치를 바꿨다면 해당 설정을 따릅니다.

아직 선택하지 않았습니다.

선택창에서 폴더 쓰기 권한을 허용해 주세요. 권한이 만료되면 다운로드 작업 탭에서 다시 요청합니다. 이 저장 방식은 지원되는 Chrome 계열 브라우저에서 사용할 수 있습니다.

비워 두면 브라우저의 다운로드 폴더에 저장합니다. 절대 경로와 상위 폴더(..)는 사용할 수 없습니다. 직접 선택한 폴더에는 적용되지 않습니다.

Safari의 저장 위치는 Safari → 설정 → 일반 → 파일 다운로드 위치에서 변경하세요. Safari에서는 다운로드 요청을 브라우저에 전달한 뒤, 다운로드 목록에서 실제 저장 결과를 확인해야 합니다.

다운로드 현황 ↗브라우저에서 직접 동작합니다.
