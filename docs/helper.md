# 로컬 도우미 포함판

도우미 포함 확장은 폴더 전체 다운로드와 배속을 제공하면서, Python 도우미로 영상을 저장합니다. HLS를 FFmpeg로 MP4에 담고 FFprobe로 결과를 확인하며, 완료 파일의 중복 저장을 방지합니다. 여러 화면이 있는 강의는 스트림별 MP4로 저장하고 화면 합성·시간 오프셋 조정·별도 음성 결합은 하지 않습니다. 암호화된 HLS와 진행 중 방송은 지원하지 않습니다.

## 시작하기

필수 프로그램은 Python 3.9 이상, FFmpeg와 FFprobe입니다. 추가 Python 패키지는 필요하지 않습니다. 릴리스 ZIP은 도우미 소스와 실행기만 포함하며, 이 프로그램들을 자동 설치하지 않습니다.

macOS에서 Homebrew를 사용한다면 FFmpeg·FFprobe를 함께 설치할 수 있습니다.

```sh
brew install ffmpeg
```

**릴리스 ZIP:** macOS에서는 `helper/start.command`를 더블클릭합니다. 다른 환경에서는 `helper/` 폴더에서 다음을 실행합니다.

```sh
python3 panopto_download.py
```

**저장소 소스:** 저장소 루트의 `start.command`를 실행하거나, 루트에서 같은 Python 명령을 실행합니다. Chrome은 `extension-helper/`를 로드합니다. Safari 빌드는 `bash scripts/build-safari.sh --variant with-helper YOUR_TEAM_ID`입니다. 릴리스 ZIP 안의 확장 폴더 이름은 선택한 방식과 관계없이 `extension/`입니다.

다운로드 중에는 도우미 터미널을 열어 두세요. 종료는 `Ctrl+C`입니다.

## 확장 연결

1. 도우미를 시작하고 `http://127.0.0.1:8765`를 엽니다.
2. **확장 프로그램 연결 코드**를 복사합니다.
3. 도우미 포함 확장의 설정에 코드를 붙여 넣고 **저장 · 연결**을 누릅니다.
4. 로그인한 Panopto 페이지를 새로고침하고 현재 영상 또는 폴더 전체 다운로드를 시작합니다.

도우미와 강의 탭을 유지하세요. 폴더 대기열은 강의 탭에서 영상 정보를 가져옵니다. 팝업은 닫아도 됩니다. 도우미에 이미 제출한 작업은 도우미가 처리하지만, 강의 탭을 닫거나 로그인이 만료되면 아직 제출하지 않은 영상은 실패할 수 있습니다.

## 저장 위치

처음 실행할 때 기본값은 `~/Downloads`입니다. 확장 설정이나 도우미 관리 화면에서 `~/Movies/Lectures` 같은 다른 경로를 지정할 수 있습니다. 이 설정은 로컬 도우미에 저장되어 연결된 브라우저가 공유합니다.

변경한 위치는 아직 도우미에 제출하지 않은 작업부터 적용됩니다. 이미 제출한 작업은 제출 당시 경로를 사용합니다. 시작할 때 경로를 지정하려면 다음을 실행합니다.

```sh
python3 panopto_download.py --output ~/Movies/Lectures
```

다운로드 진행 상황과 취소는 확장 팝업 또는 로컬 관리 화면에서 확인합니다. 같은 영상의 완료 파일이 같은 저장 위치에 남아 있으면 다시 저장하지 않습니다.

## 연결 정보

도우미는 `127.0.0.1:8765`에만 바인딩합니다. 확장은 연결 코드를 인증 헤더로 전달하고, 재생 주소를 이 컴퓨터의 도우미에 보내 다운로드합니다. Panopto 로그인 쿠키나 비밀번호를 내보내지 않으며 외부 분석·추적 서버를 사용하지 않습니다. 서명된 재생 URL은 완료 내역에 저장하지 않습니다.

연결 코드는 확장의 로컬 저장소와 도우미의 `.state/token`에 저장됩니다. `.state/`에는 설정과 완료 내역도 있으므로 개인 설정으로 보관하고 공개 저장소에 올리지 마세요. 확장은 기본 포트 8765에 연결하므로 도우미의 포트를 변경하지 마세요.

확장 프로그램 전용판은 이 도우미와 연결하지 않습니다. 방식 전환 시 기존 확장을 먼저 비활성화하며, 설정·작업 내역은 자동 이전되지 않습니다.
